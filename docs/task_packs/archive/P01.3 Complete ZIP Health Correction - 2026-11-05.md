The preceding diagnostic-health file was a different, already delivered component. The old passive-health test stopped at `collect_components()`, leaving final ZIP assembly untested for this addition.

Add the health member after existing startup, diagnostic-health and operations members. Preserve their priority and the incident-first archive. Reuse existing compression admission, descriptor hashing, frozen continuation, actor binding, expiry, retry and byte budgets. Unavailable health remains optional and accurately labelled. A health member that cannot fit is retained for the existing diagnostic continuation rather than silently omitted.

No new abstraction, worker, retry, reader lock, provider work, SQL query, schema, configuration or business-state persistence is introduced. The existing service layer owns the correction. Helpers reused: `bundle.descriptor`, `bundle.retain`, `bundle.manifest`, `bundle.anchor_initial` and the existing diagnostic-part reader.
