## Proof design

Each route has a valid final disposition plus exact token, version, account, storage, consumer, ownership, fence, resource, queued-work, stream, producer exclusion, account exclusion, compare-and-set, audit text and reconciliation cases. Applicable branches add generation, SQL receipt, atomic request and pipeline ownership checks. Separate success cases prove idempotent acknowledgements and matching saved outcomes; a foreign marker must not be adopted.

The simulated concurrent change is applied on the actual final BEGIN TRANSACTION, after any passive preview. Structural cases use a matching changed-state token so a stale-token guard cannot conceal a missing final scope/ownership check. Stale cases retain the original token. Rollback restores the simulated concurrent state, never its earlier preview. Unexpected transport errors are recorded independently and fail the case even if original code catches an exception. The valid model uses columns verified against the authoritative ExportPreparation, ExportResource, StatsImportExecution and ExportExecutionStream definitions. Deliberately inconsistent negative states are labelled model inputs, not native fixture proposals.

The original adapter, capture service, disposition DAL, transaction/session handling, generation validator and custody code execute. SQL transport and passive snapshot context are inert substitutes. The fixture runtime exposes configuration/storage only; a business producer, snapshot writer, export queue or provider request cannot run. Cancellation fixture coverage is the retained canonical-reservation branch; pending/preflight and account-reservation branches remain outside this group's detailed scenario coverage. Source bodies inherited through the accepted settlement support remain pinned and unmodified.

Architecture/deferred/test-selection/security-routing repository-wide validators are deferred until PR handoff: this is an isolated qualification packet, not a runtime PR or deployment, and its bounded runner is the relevant execution gate.
